# Produksjonsgrunnlag for bestilling 21

Toms godkjente HD-konvertering med Astra og presis skalering/plassering fortsetter. Les c-kildeplan.md før produksjon.40beskyttede kilder er låst. Promptene brukes ordrett med separate kildekorreksjoner. Innebygd ChatGPT-bildegenerator brukes; eksakt bildemodell er ikke eksponert. Ingen originalkonturmasker, originaloppskalering som erstatningskunst eller lokal warp. Nye komponenter kan helskaleres/plasseres presist med dokumenterte rektangler. Vektorvalgene for049/077 gjelder bare de to rommene.

A eier rom089, rom090, rom092 og obj901_01.089har egne skilt/ny vinkel,090bare avskåret Sam-hode og Max-ører uten komplette kropper/våpen,092hårform på støtte i varmt lys,901tom sokkeltilstand uten hår/støtte. B eier rom091-paret og obj850_01.091er fargede tomme klær/rekvisitter, én2656×800master, klipp0/1120, overlapp416×800.850har egen flat grå/lilla surfersilhuett, øvrige kildedeler fortsatt fargede. C eier obj995_01, obj996_01 og lag002_01.995svakt mørkebrunt underlag uten gjettet logo/tekst,996avklippet UIstripe som ikke fullføres.

Lag002_01 skal være opakt RGB-rom med seks konkrete små objekter på eksakte sourceposisjoner, ikke atlas eller alfaark. Bilde_to er levert rom002-HD. Hvert av de seks objektene må være visuelt og numerisk kontrollert; manglende små lysvarianter kan skjules av korrekt grunnrom. Uendret checker har både helbildevurdering og perobjektkantkorrelasjon, men skriver bare perobjektavvik og har unntak for svake/små bokser. Lag et tydelig seksobjektkontaktark/posisjonsbevis mot faktisk source og HD. Eksisterende HD-grunnrom kan gjenbrukes utenfor dokumenterte nye lokale rettingsfelt; lokal nytegning gjøres med innebygd imagegen, ikke sourcepiksler/masker. Ikke importerobjektene fra lag002_02..05 i lag01.

Root eier samlet QA, global kø/logger, Git og levering. Råforsøk, faktisk prompt, oppskrift, notater, SHA, kildehash, kontroller og manifest kreves. Ingen motor-/pipelinekode, beskyttede jobbfiler eller Claude-eide ordre-/statusfiler endres. Teknisk kontroll, motiv-QA, ny individuell brukergodkjenning, import og runtime holdes separate.
