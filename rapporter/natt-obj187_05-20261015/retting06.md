# Sjette forsøk

Femte forsøk fikk direkte format 1430 x 1100, sideforhold nøyaktig 1,3. Egenkontroll: SJEKK, skift 0,99, blokk 1,47 og kantlikhet 0,86. Ingen grå kant eller ekstra skygge. Nytt forsøk bruker original 05 som geometri igjen og godkjent 01 som bilde to, med direkte utformat og konkrete kildekoordinater for klubbe, grep og hull. Originalen, ikke forrige generering, styrer plasseringen.
