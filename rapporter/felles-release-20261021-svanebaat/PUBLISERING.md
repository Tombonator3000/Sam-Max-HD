# Publisering av fellesutgaven

Fellesutgaven sam-max-hd-2026-10-21-svanebaat er publisert og Latest-bekreftet. Begge faktiske fellesvedlegg er lastet ned på nytt, med SHA-filer og alle fire vedleggsdigester kontrollert. Se publisert.json og release-publisert.json for eksakte SHA, kjøretid og byggegrunnlag.

GitHub CLI opprettet én kladd, release-id 419574688, med riktig tagg, kode og notat. Det første API-oppslaget rett etter opprettelsen fant den ennå ikke. Publiseringshjelperen stoppet før opplasting. Det påfølgende lesekallet fant samme kladd med samme tagg, mål-SHA og uendret notat, uten vedlegg. Release-id ble festet i forsøksfilen, og samme forsøk ble gjenopptatt. Ingen ny kladd eller duplisert release ble opprettet. Alle fire vedlegg ble kontrollert før publisering og deretter hentet på nytt fra fellesutgaven.

Det automatiske ekstra Windows-bygget fra den nye taggen er registrert i publisert.json. Nativefrysen beholdes til dette bygget er avsluttet. Ingen ekstra manuell bygging, avbrytelse eller endring i de ferdige fellesvedleggene er foretatt.
