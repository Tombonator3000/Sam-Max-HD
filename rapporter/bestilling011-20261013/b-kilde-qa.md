# Bestilling 11 gruppe B kilde-QA

Fire leveranser fra to innebygde imagegen-genereringer, ett forsøk per rom. Eksakt bildemodellnavn ikke eksponert. Alle originaldeler og helscener sett, metadata/prompter og C sin kildeplan lest før generering. Godkjent stilanker stil/rom007_del1av2.png gir bare strek/pensel. Ordrette originalprompter og separate presiseringer bevart.

Rom051: SAVAGE / JUNGLE / INN og WELCOME / PODIATRALLY / GIFTED er kontrollert med kildens radbrudd og avkutting. Grønn skiltøgle med rød tunge og krøllet hale, dekorativ vulkan, tak, palmer, bro og vannløp beholdt. Tre biler totalt: svart/hvit DeSoto samt grå og rød bil til høyre. Ingen gjester eller nye biler. Brostolper og rekkverk følger kildeplassering. Fin takstråtekstur, blomster, bilgrill og vannkant er HD-tolkninger.

Rom052: THE / REPTILE / QUEEN og kildens COLOR nederst bevart. Kvinneskikkelse/slange på plakat følger motivet, små kredittstreker er ikke gitt navn. Tukan med nebb mot høyre, hvilende grønn øgle med krum hale på svart stein, stivt grått steinhode over mørke tomhyller, tre små veggrammer, gardinåpning og glassdør beholdt. Ingen resepsjonist eller nye skilt. Øglens øyelokk/ansiktslinjer og små fibre/steindetaljer er tolkninger; hvilestilling er beholdt. Oransje/gult mønster gjengitt etter farge/form uten nye flammer eller antatt mekanikk.

Master rom051 er 1856×800 med delskift320 og overlapp1216×800. Master rom052 er 1920×800 med delskift384 og overlapp1152×800. Overlapper er byte-identiske. Global normalisering fra generatorcanvas og eksakt klipp er dokumentert i b-levering.py.txt; ingen lokal warp eller originalpikselmaskering. Alle 16 egne beskyttede kilder er uendret mot kildehash.json.

Uendret sjekk_leveranse.py gir fire OK: rom051 del1 skift0.16/blokk0.62/kant0.95, del2 0.18/0.76/0.95; rom052 del1 0.06/0.14/0.97, del2 0.05/0.41/0.96. Statisk visuell sammenligning utført. Runtime, maskesamspill, dynamisk palett og animasjon er ikke testet; ny individuell brukergodkjenning=false. Teknisk OK er ikke bildegodkjenning.
