Sam & Max HD for Linux og Windows med 1776 native HD-figurruter, 122 flere enn forrige kveldspakke. Ny grafikk: Sam med gripearm, fiskemagnet og humørring i hyssingmuseet, og Sam/Max i strikksele i grotten. HD-grafikken produseres fortsatt.

Last ned Linux-AppImage eller Windows-ZIP under Assets. Linux: gjør AppImage kjørbar og start den. Windows: pakk ut hele ZIP-filen og start «Sam og Max HD.bat». Hver pakke har en SHA-256-fil.

Begge pakker er bygget fra main 346f27c0e5da1e2f3b8c29ce02ce6fb3c9e436f4 og hd-mod 6513908aa6d47dd73abd58f6f101ff9641c25d6b. Begge faktiske nedlastinger og alle fire API-digester/størrelser er kontrollert. Alle 20 017 runtime moddfiler er identiske mellom pakkene og publisert modd. Linux består oppstart og Debian 12; Windows består arbeidsflytens automatiserte oppstartstest.

Nedlastet Linux: ni målrettede prøver med inventar, akvarium, cafeteriarør og alle 122 nye native ruter. Alle 122 observert, 415 skjermbufferkontroller fra figurstart uten avvik. Seks kjente oppstartsavvik er som grunnlaget. Ikke full gjennomspilling, interaktiv Windows-test eller ny Tom-/Claude-godkjenning. Dokumenterte grafikkreturer og omrissmerknader står fortsatt åpne.
