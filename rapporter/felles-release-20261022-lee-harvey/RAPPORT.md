# Felles Linux og Windows med 3641 HD-lag

Publisert og bekreftet Latest: https://github.com/Tombonator3000/Sam-Max-HD/releases/tag/sam-max-hd-2026-10-22-lee-harvey. Begge faktiske nedlastinger, fire vedleggsdigester og alle 21884 runtime-modfiler per pakke er bekreftet. De publiserte fellesvedleggene er hentet tilbake og kontrollert på nytt. 45 flere native lag enn forrige fellesutgave. 41 tidligere releaser er bevart.

Alle 45 Lee-Harvey-lag er observert og visuelt sett som hele figurvarianter i den faktiske Linux-pakken, sammen med fire hele skjermbilder. 1360 bufferkontroller, 1351 null. De samme ni kjente feilkoordinatene og begge RGB-verdiene er identiske. Primærprøven er ikke avviksfri. Ingen full naturlig gjennomspilling, interaktiv Windows, ny webtest eller Tom-/Claude-godkjenning.

Nativefrys beholdes mens forventet Windows-taggbygg 39733813358 pågår. Ingen nye bygg eller nativepublisering før grønt taggbygg og kontroll av gjeldende fjern-SHA. Se publisert.json, moddfiler-kontroll.json og linux-kontroll.json. All grafikk er ikke ferdig.
