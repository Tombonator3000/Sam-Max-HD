# H330 fase1987

Faktisk innebygd image_gen, uendret råbilde, prompt og referansehasher bevart. Original fase og rom35, nabofaser ved halerotoren og Sam er sett før motivene. Sam er eneste godkjente stilanker. Egne tidligere bilder er redigeringsmål, ikke godkjent design.

Hel halerotor med bredere grønn nedre høyre skulder, naturlig ny RGBA. Egen alfa endres i12810piksler. Direkte form/åpning3/0 og seks positive materialfester. Kildegrønne halerot løses ikke samlet. Retur, H327 beholdes.

Seks egne komposisjoner/native-PNG/RGBA har byteeksakt replay fra34 egne råbilder, med sperrer mot originalbilder som produksjonspiksler. Hele egne deler registreres samlet etter egen alfaramme. Myk16px overgang, alle piksler utenfor egne rektangler er bytebevart. H326/H327/H328 og brunprøven beholder egen alfa; H329/H330 prøver naturlig ny RGBA uten originalmasker. Frosne heltransformer,3HD og12prosent er uendret. Ingen kildepunktmaling. Se replay-kantfarger.json/rutekart-kantfarger.json.

Ingen hel resultat.png, formelt native mottak, publisering eller Tom-/Claude-godkjenning. Bare H327/egen-del-RGB er lokalt motorobservert i én ny kontrollert160bilders kjøring. Dette gir ingen helskjermregresjon, naturlig/Windows-/webgjennomspilling eller stilgodkjenning.
