# Kladdopprettelsen er bekreftet

GitHub CLI opprettet kladden og returnerte en midlertidig untagged-URL. Umiddelbar API-liste viste den ennå ikke, og sikringen stanset opplasting. Ingen ny kladd ble opprettet. Ved ny lesing ble kladd419381790 bekreftet med eksakt tag, kode, full utgivelsestekst og null vedlegg. Det samme forsøket gjenopptas med kjent release-ID. Dette er API-forsinkelse, ingen feil i grafikk eller pakker.
