Linux og Windows har nå samme kontrollerte grafikkpakke med **2333 native HD-ruter**, 50 flere enn forrige fellesutgave. Sams auberginekast i alkoven er med i begge pakker, inklusive hånd, frukt, alle overlag og sluttposer. Hele det gyldige kostymet har 50 ruter. Resten av HD-grafikken er fortsatt under arbeid.

Last ned **SamMaxHD-Windows.zip** for Windows eller **SamMaxHD-x86_64.AppImage** for Linux. Spillet og talen følger med. Linux: gjør filen kjørbar og start den. Ctrl+H bytter grafikk, F5 åpner originalmenyen.

Begge faktiske nedlastinger og SHA-filer er kontrollert. Alle 20 574 runtime moddfiler per pakke er identiske med publisert modd og hverandre. Linux: fem pakkeprøver og fem sammenlignbare 2283-grunnlagsprøver med samme nye binær. Alle 50 nye ruter er observert; 179 skjermbufferkontroller uten avvik. Inventar, akvarium, cafeteria og begge Sam-kast er visuelt kontrollert. Windows har grønt pakkebygg, startprøve og samme grafikkfiler. Dette er ikke full gjennomspilling eller en ny interaktiv Windows-/webtest. Kjente små kantrester og øvrige uferdige figurer står fortsatt i arbeidslisten.
