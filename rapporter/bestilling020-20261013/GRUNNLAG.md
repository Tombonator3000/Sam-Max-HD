# Produksjonsgrunnlag for bestilling 20

Toms videre HD-bestilling med Astra og presis skalering/plassering gjelder. Les a-kildeplan.md før produksjon.40beskyttede kilder er låst. Innebygd ChatGPT-bildegenerator brukes; eksakt bildemodell er ikke eksponert. Promptene bevares ordrett med separate kildekorreksjoner. Ingen originalmasker, lokal warp eller originaloppskalering som erstatningskunst. Genererte komponenter kan helskaleres/plasseres med dokumenterte rektangler. Vektortillatelsene for049/077 gjelder bare disse rommene.

A eier rom083, obj832_01 og rom085. Skybakgrunnen er tom; de ti figurene ligger i eget obj832 med egne klær/rekvisitter/hvit høyrevariant, ikke standard naken Max. Dinosaurattraksjonens hode er eget nærbilde med opprinnelig tenner/mørke hulrom, uten nye levende detaljer.

B eier alle tre rom084-delene. Én3840×800master, klipp0/1152/2304, overlapp384×800. Tre skjeve fargelagte kort, hver med Wax Me. Ingen MAX'S WAX-tittel eller separat fargestiftboks. Alle tre kortscener og avklipp følger originalen.

C eier rom086, obj839_01, rom087, rom088. Tettere grantrær i839 er egen tilstand, ikke blindt rom086-klipp. Bevar avklippet skilt/markedstekst, ikke fullfør utenfor synlighet. De tegnede bybildene er kildefasit, ingen ny fotogeografi.

Root eier samlet motiv-QA, kilde-/SHA-/paddingkontroll, kø, logger og Git. Råforsøk, faktisk prompt, oppskrift, notater, familie-QA, manifest og uendret checker kreves. Dokumenter SJEKK og konkrete avvik, ingen automatisk oppgradering. Teknisk kontroll, ny individuell godkjenning, import og runtime holdes separate. Ingen motor-/pipelinekode eller Claude-eide ordre-/statusfiler endres.
