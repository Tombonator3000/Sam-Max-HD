# Produksjonsgrunnlag for bestilling 19

Toms godkjente videre HD-konvertering med Astra og presis skalering/plassering fortsetter. Les c-kildeplan.md før produksjon. 40 beskyttede kildefiler er låst; promptene skal ikke endres. Innebygd ChatGPT-bildegenerator brukes, eksakt bildemodell ikke eksponert. Vektortillatelse for049 overføres ikke til denne bestillingen.

A eier rom079 begge deler fra én master2560×800 og obj819 med egen blå bakgrunnsvariant. Venstre kule er opp-ned, ikke ekstra horisontalt speilvendt; hånd, innhold og skjeve originalglyffer bevares. B eier obj821/822/823. C eier obj828/829/830/831. Ressursenes snake-navn betyr ikke slanger: dette er Jesse James' innskrumpede hånd på grønn golfballhenter. B-variantene holder fiskemagnet, med farget ring bare i822/823. C er tom åpen hånd, fem fingre, avklipte grønne segmenter og egen pose per kilde. Ressursregister/primær hintbok støtter identiteten, ikke runtime-rekkefølge.

Generer fra faktisk original og godkjente identitetsankere. Ordrett prompt følges av separat kildekorreksjon der romnavn/notes er feil. Ingen originalkonturmasker, lokal warp eller kopiert originaloppskalering. Nye komponenter kan helskaleres/plasseres presist med dokumenterte rektangler og egen oppskrift. Alt svart tomrom og konkret avkutting bevares. Root kontrollerer samlet familie og eier global kø, logger, Git og levering. Råforsøk, prompter, oppskrifter, SHA, notater, kildehash og uendret checker bevares. Teknisk kontroll, motiv-QA, ny individuell godkjenning og runtime er separate tilstander. Ingen motor-/pipelinekode eller Claude-eide ordre-/statusfiler endres.
