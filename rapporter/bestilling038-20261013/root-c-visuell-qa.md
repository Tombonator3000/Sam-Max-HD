# Rotkontroll: to C-lag

Original/HD for alle tre felt og begge helscener er visuelt sammenlignet i c-objektqa-1.png og c-helsceneqa.png. Åpen dør er svart og tom; turbusspalett, gul stjerne/CB, avklipping og bil/busk foran er beholdt. Lave orange ermet med rosa hånd er egen lav stilling, ikke den forkastede høye armen. Ingen tydelig rektangelskjøt ved normal helscenevisning.

Tegningsforbehold: bussens skrift, stjerne, grill og lys er jevnere og mer modellerte; hånd/erm har rundere konturer enn kildepikslene. Ingen semantisk identitetsendring er observert. Teknisk sluttkontroll er separat; individuell brukergodkjenning, import og runtime er ikke utført.
