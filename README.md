# Sam-Max-HD: spilldata

Spillfilene til *Sam & Max Hit the Road*, engelsk CD-utgave (SAMNMAX.000 MD5 `d917f311a448e3cc7239c31bddb00dd2`). Grenen har ingen felles historikk med `main`.

Hent dem med `tools/hent_spilldata.sh` fra `main`. Skriptet legger filene i `game/`, setter sammen `MONSTER.SOU` (talen, i deler på 90 MB fordi GitHub ikke tar filer over 100 MB) og sjekker `game/SHA256SUMS`.

`MT32_CONTROL.ROM` og `MT32_PCM.ROM` er Roland MT-32-ROM for musikkemulering i ScummVM. De er valgfrie.

Spillet tilhører Disney/Lucasfilm. Filene brukes bare til HD-arbeidet i dette repoet.
